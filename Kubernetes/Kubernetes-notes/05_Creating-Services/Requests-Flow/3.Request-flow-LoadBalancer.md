## Interview-Grade Answer

> "In a LoadBalancer Service, an external cloud load balancer is provisioned by the cloud provider. Client traffic first reaches the external load balancer, which forwards it to a NodePort on one of the worker nodes. kube-proxy on that node then selects one of the backend Pods associated with the Service and routes the traffic to it. The cloud load balancer distributes traffic across nodes, while kube-proxy distributes traffic across Pods."

### Memory Trick

```text id="22"
ClusterIP
   Pod -> Service -> Pod

NodePort
   Browser -> Node -> Pod

LoadBalancer
   Browser -> LB -> Node -> Pod
```
